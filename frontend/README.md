# 💻 NFCKey Web Frontend

Direktori ini berisi antarmuka pengguna berbasis web untuk sistem **NFCKey (Smart NFC Attendance & Door Access System)**.

---

## 📂 Struktur Direktori

- **[`react/`](./react/)**: Aplikasi Single Page Application (SPA) berbasis React 19, TypeScript, Vite, Tailwind CSS, dan Lucide Icons.
  - Dashboard monitoring real-time
  - Streaming log presensi langsung via Supabase Realtime WebSockets
  - CRUD kartu RFID/NFC, pengguna, dan perangkat
  - Pengaturan sistem dan pengujian alert

Untuk panduan lengkap setup dan build, silakan buka [Panduan React Dashboard](./react/README.md).
